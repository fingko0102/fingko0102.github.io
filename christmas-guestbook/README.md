# 크리스마스 디지털 방명록 (Christmas Guestbook)

QR로 접속한 휴대폰에서 그림과 한마디를 보내면, 미디어월(큰 화면)에 오너먼트처럼 떠오르는
크리스마스 방명록입니다. 서버 없이 GitHub Pages에서 동작합니다.

- 미디어월: https://fingko0102.github.io/christmas-guestbook/
- 참여(그리기): https://fingko0102.github.io/christmas-guestbook/?mode=draw

## 화면

| 화면 | 주소 | 설명 |
| --- | --- | --- |
| 미디어월 | `?mode=wall&room=XXXX` (데스크톱은 기본값) | 밤하늘·눈·트리 위로 방명록 그림이 떠다닙니다. 오른쪽 아래에 참여 QR·방 코드가 있습니다. |
| 그리기 | `?mode=draw&room=XXXX` | 휴대폰용 캔버스. QR을 스캔하면 이 화면으로 바로 들어옵니다. |

모든 화면이 통합 방 코드 **`XMAS`** 하나로 열립니다. URL에 `?room=MERRY`처럼 예전 방 코드가
들어 있어도 무시하고 `XMAS`로 통일되므로(주소도 `?room=XMAS`로 정리됩니다), 예전에 복사해 둔
링크·QR로 들어와도 방이 갈라지지 않고 하나의 미디어월에 모입니다.
미디어월과 그리기 화면이 같은 방을 쓰므로, 어디서 그린 그림이든 하나의 미디어월에 모입니다.

## 쓰는 법

1. 큰 화면에서 미디어월을 엽니다. 화면 아래쪽 QR을 휴대폰 카메라로 스캔합니다.
2. 휴대폰에서 그림을 그리고 이름·한마디를 적은 뒤 **미디어월에 보내기**를 누릅니다.
3. 미디어월에 그림이 반짝이며 떠오릅니다. 그림을 누르면 크게 볼 수 있습니다.
   크게 보기에서 **수정**을 누르면 그림·이름·한마디를 그대로 불러와 고칠 수 있습니다
   (기존 그림 위에 이어 그리거나, 전체 지우고 새로 그린 뒤 **수정 저장**).
4. 그리는 화면의 팔레트에는 흰색부터 검은색까지 9가지 색이 있습니다.
4. 미디어월에서 바로 그려보려면 **이 화면에서 바로 그려보기**를 누릅니다.
5. 그림을 지우려면 그 그림을 **0.6초 이상 꾹 누른 뒤** 비밀번호를 넣습니다.
   그 그림만 지워지고, 열려 있는 다른 미디어월에서도 곧 사라집니다. (비밀번호는 관리자만 압니다.)

## 그림 수정

미디어월에서 그림을 눌러 열리는 보기 창(과 꾹 누르기 창)의 **수정** 버튼으로 그림·이름·한마디를
고칩니다. 기존 그림은 캔버스 맨 아래층에 투명 PNG로 그려진 채 열리므로 그 위에 이어 그리거나,
전체 지우기로 비우고 새로 그릴 수 있습니다. 저장하면 **같은 `id`에 `ts`만 더 크게** 올려
보내므로(`ts = max(Date.now(), oldTs + 1)`) 로컬 저장소·서버 DB(Worker의 `mergeArts`)·
열려 있는 다른 월이 모두 같은 항목을 덮어씁니다. 새로고침하거나 다른 기기에서 열어도 수정본이 남습니다.

## 서버 DB 연결 (선택)

서버가 배포되어 있으면 자동으로 붙고, 없으면 조용히 GitHub Pages만으로 동작합니다.

- 기본 주소: `https://christmas-guestbook.fingko.workers.dev`
- `?api=https://내-서버` 로 다른 주소를 쓰고, `?api=off` 로 서버를 끕니다.
- 서버 규약:

| 요청 | 하는 일 |
| --- | --- |
| `GET /arts?room=ROOM` | 그림 목록 → `[{id,url,name,msg,ts}]` 또는 `{arts:[...]}` |
| `POST /arts?room=ROOM` | 그림 저장 — 본문은 그림 1개 객체 또는 `{arts:[…]}`(여러 장, 최대 100장) |
| `POST /delete?room=ROOM` | `{id, password}` → 비밀번호가 틀리면 `403` + `{"error":"wrong_password"}` |

붙으면 미디어월은 시작할 때 서버 그림을 모두 받아 오고, 내 기기에만 있던 그림을 올리며,
4초마다 새 그림·지운 그림을 맞춥니다. 그리기 화면도 보낼 때 서버에 함께 저장합니다.
내 기기에만 있던 그림은 **한 번의 `{arts:[…]}` 요청**으로 모아 올립니다(한 장씩 동시에 보내면
서버가 나중 요청으로 앞 요청을 덮어써 그림이 유실됩니다).
상태 배지는 서버 DB가 응답하면 실시간(P2P) 연결 상태와 상관없이 바로 초록 불
`서버 DB 연결됨 · 통합 방명록`이 되고(실시간까지 붙으면 `· 실시간 연결` 표시), 그리기 화면도
`월 대기 중` 대신 `서버 DB 연결됨`으로 표시됩니다.

## 동작 방식

- **여러 미디어월**: 첫 번째 미디어월이 Host(`fgxmas-XMAS-wall`)가 되고, 두 번째 이후
  미디어월은 Host에 붙어(`wall-peer`) 서로 가진 그림 목록(`sync-arts`)을 맞춥니다.
  Host가 닫히면 남은 미디어월이 Host 자리를 자동으로 이어받습니다.
- **같은 기기/브라우저**: `BroadcastChannel` + `localStorage`로 탭 사이를 바로 잇습니다.
- **다른 기기(휴대폰 ↔ 미디어월)**: PeerJS(WebRTC) 데이터 채널로 그림을 직접 주고받습니다
  (`vendor/peerjs.min.js`, 공개 시그널링 서버 사용). 미디어월이 열려 있어야 연결됩니다.
- **저장**: 그림은 `fgxmas:<방>:arts`(최대 100개)와 `fgxmas:<방>:lastart`에 저장되고,
  미디어월은 저장된 모든 방의 그림을 시간순으로 합쳐 보여 줍니다. 기존 키는 지우지 않습니다.
- **삭제**: 꾹 누르기로 지우면 그 id를 `fgxmas:<방>:deleted`에 기록(tombstone)하고
  모든 `fgxmas:*:arts`/`fgxmas:*:lastart`에서 그 id만 빼냅니다. 비밀번호는 SHA-256 해시로
  비교하며 평문은 코드에 두지 않습니다. `BroadcastChannel`·PeerJS로 다른 월에도 바로 알립니다.
- 화면에 동시에 떠 있는 그림은 최근 44개까지이고, 그보다 예전 그림은 저장소에 그대로 남습니다.
- 그림은 캔버스에서 여백을 잘라 투명 PNG로 만들어 보냅니다.

## 한계

서버 DB가 연결되지 않은 상태에서는 **모든 미디어월이 꺼져 있으면 다른 기기의 그림은 자동으로 모이지 않습니다.**
(그 기기의 브라우저 저장소에는 남아 있어, 그 기기에서 미디어월을 열면 그대로 보입니다.
미디어월이 하나라도 켜져 있거나 같은 기기라면 그림이 동기화됩니다.) 서버 DB가 붙으면 이 한계가 사라집니다.

## 파일 구성

```
index.html            화면 구조 (미디어월 / 그리기)
style.css             스타일
js/scene.js           밤하늘 별·눈 캔버스
js/drawer.js          그리기 캔버스 컴포넌트 (팔레트·굵기·지우개·되돌리기·보내기)
js/store.js           저장 계층 (모든 방의 그림 통합·병합 저장, 삭제 기록)
js/api.js             서버 DB(Cloudflare Worker) 연동
js/bus.js             PeerJS + BroadcastChannel + localStorage 연결 계층
js/wall.js            미디어월 (QR·오너먼트 배치·저장/복원·꾹 눌러 삭제·서버 동기화)
js/draw-page.js       그리기 화면
js/ui.js              토스트·모달·클립보드
js/app.js             모드/방 코드 결정
vendor/               qrcode-generator(MIT), peerjs(MIT)
```

`?debug=1`을 붙이면 오류를 `window.__errs`에 모아 둡니다(검사용).
