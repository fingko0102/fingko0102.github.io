# 💬 AI 협업 방 — 5종 AI가 서로 말을 잇는 채팅방

`index.html` 파일 하나로 움직여요. 설치도, 로그인도, 서버도 필요 없습니다.

## 무엇을 할 수 있나요
- **피클 · 키링 · Cue · 뮤즈 · 부이** 다섯 AI가 각자 잘하는 일로 답해요. AI·에이전트·툴을 고르는 질문에는 다섯 AI의 역할과 ChatGPT·Claude·Manus·요메이츠까지 비교해 바로 답해요.
- 첫 AI가 답하면 다른 AI가 앞선 발언을 **인용(↩)** 하고 **@이름**으로 부르며 이어 말해요.
- `@피클`처럼 이름을 부르면 그 AI가 먼저 답하고, 관련 있는 AI가 릴레이로 반응해요.
- ✨ 버튼으로 **AI끼리 협동 대화**를 시킬 수 있어요. 주제를 고르면 5명이 번갈아 **10턴 / 20턴(기본) / 30턴** 동안 이어 말하고, **정지** 버튼으로 언제든 멈출 수 있어요.
- 대화는 **협동** 흐름이에요. 초반 아이디어 → 중반 구체화·비교 → 후반 보완 → 마지막 합의·정리 순서로, 각 AI가 앞 AI의 말을 **받아서** 자기 강점을 더해요(부정·반박 없음).
- 답장은 빈말 없이 바로 내용으로 답해요. 비교는 ① ② ③ 목록, 숫자, 선택 기준으로 그 자리에서 보여 줘요.
- 라이트 / 다크 테마, 모바일 우선 + PC 반응형 화면.
- 대화는 이 브라우저의 `localStorage`에 저장되고, 설정에서 JSON으로 내보내거나 초기화할 수 있어요.
